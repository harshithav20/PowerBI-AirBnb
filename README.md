# Airbnb Travel & Tourism Dashboard

An interactive **Power BI dashboard** designed to analyze travel destinations and provide geographical and distance-based insights.

## Project Overview

This project visualizes travel destination data using Power BI. It helps users explore destination cities, travel distances, geographic coordinates, and other travel-related information through interactive visualizations.

## Dashboard Features

- Interactive destination map
- Popular destination overview
- Travel distance analysis
- Destination-wise comparison
- Distance in kilometers and miles
- Source and destination geographical analysis
- Travel duration insights
- Interactive filtering by destination city

## Visualizations Used

- Map
- Cards
- Bar Chart
- Pie Chart
- Gauge Charts
- Filters and Slicers

## Data Fields

The dashboard analyzes fields such as:

- Source City
- Destination City
- Source Latitude
- Source Longitude
- Destination Latitude
- Destination Longitude
- Distance (km)
- Distance (miles)
- Duration (hours)

## Tools Used

- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis

## Purpose

The objective of this project is to transform travel destination data into an interactive dashboard that makes it easier to understand travel distances, destination locations, and geographical patterns.
